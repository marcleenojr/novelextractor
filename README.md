# novelextractor
Isang makapangyarihang JavaScript tool na idinisenyo para sa mabilis at awtomatikong pag-extract ng mga kuwento sa Webnovel. Kaya nitong i-scrape ang bawat chapter nang buo, malinis, at walang kalat. Perpekto para sa mga gustong magbasa offline, mag-archive, o mag-compile ng kanilang mga paboritong web novel sa isang click!
