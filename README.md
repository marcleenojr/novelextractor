Ang simpleng script na ito ay nag-e-extract at nag-ti-trigger ng download para sa lahat ng chapter mula sa isang page ng www.webnovel.com. Hinahanap nito ang lahat ng chapter at kinukuha ang teksto ng bawat talata (paragraph) sa loob ng mga ito.
Paano ito gamitin:
1. Pumunta sa Webnovel page kung saan nandoon ang lahat ng chapter na gusto mong i-download.
2. Mag-scroll pababa mula sa pinakaunang chapter hanggang sa pinakahuling chapter.
3. Pagdating sa huling chapter, huminto sa pag-scroll at hintaying mag-load nang buo ang lahat ng chapters sa page.
4. Kapag loaded na ang lahat, mag-right-click sa page at piliin ang "Inspect" para mabuksan ang developer tools.
5. Pumunta sa "Console" tab sa loob ng developer tools.
6. Kopyahin (copy) at i-paste ang script na ito sa console, pagkatapos ay pindutin ang Enter.
7. Awtomatikong kukunin at ida-download ng script ang lahat ng chapter bilang isang buong text (.txt) file.
Tapos na!
